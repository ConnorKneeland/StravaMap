Apple Watch Workout Routes

To draw a line on your map from an Apple Watch workout, record the activity using one of the supported workout types below. These workout types can produce an Apple Health workout route that the map can use as a polyline.

If you want the activity to appear under a different name on your map, you can assign a custom workout label afterward. The custom label changes how the activity is displayed, but the workout should still be recorded using one of the supported Apple Watch workout types below so that route data is captured.

Frequently Asked Questions

Can I create my own workout label?

Yes. You can assign a custom label to the workout so it appears on the map using the activity name you prefer.

Does a custom label create route data?

No. The custom label only changes how the workout is categorized or displayed on the map. Route data comes from the Apple Watch workout itself, so you should record the activity using one of the supported workout types listed above.

What if my activity is not listed?

You selected an activity that does not record a GPS polyline. Choose the supported Apple Watch workout type that best matches how the activity is being performed and then assign your preferred custom label afterward. For example, a canoe trip can be recorded as Paddling and labeled “Canoe” on the map.
