Make Your Map privacy

Last updated August 5, 2026

Make Your Map is a personal workout-map project. Its Intervals.icu proof of concept is available only for test accounts that the project owner manually links to an approved URL slug.

What is collected

After an account owner supplies an Intervals.icu Athlete ID and personal API key for testing, the server reads completed Intervals.icu activities. An authorized owner may also upload a Strava account-export ZIP to add historical workouts to the ICU map. Stored data can include activity titles, sport types, dates, distances, times, training metrics, detected intervals, device or upstream-source information, route coordinates, and activity streams. The ZIP importer reads workout metadata and FIT, GPX, or TCX activity files; unrelated account-export content such as photos is ignored.

How it is used and shared

The data is used to synchronize and render the workout map, charts, playback, notes, collections, and map customizations. Cached map data is publicly viewable by its assigned URL slug. The Intervals.icu personal API key is encrypted on the server, is never sent to the browser, and is not sold or used for advertising.

Retention and security

Activity data is retained in MongoDB while the Intervals.icu map is active. Strava-export workouts are stored in the separate ICU-map activity collection and do not replace or delete records in the existing Strava activity collection. When two source records represent the same workout, both are retained and the record with more detailed data is displayed. Provider credentials are encrypted with AES-256-GCM. Short-lived signed browser sessions are used for synchronization, ZIP uploads, and edits. Uploaded ZIP files are processed through a temporary server file and removed after processing.

Revocation and deletion

An account owner may regenerate or clear the personal API key in Intervals.icu at any time; doing so stops future synchronization until a replacement is provisioned. To request deletion of the connection, encrypted credential, cached Intervals.icu activities, notes, collections, and customizations, contact the repository owner through the Make Your Map GitHub repository. Data will be deleted from the active database after the request is verified.

Service providers

The project uses Intervals.icu as the activity provider, Railway for the server, MongoDB for persistence, Netlify for the website, and map-tile providers used by the map interface. Their own privacy terms may also apply.
